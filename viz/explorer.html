What is included

Only exact scores over all 232 inputs: eval --exact outputs, race logs run without sampled verification (their start and accepted scores are exact), and verified race tables. Sampled screens are left out. Built by analysis/collect_explored32.py --json.

Folding negation

For odd m, −m keeps bit 0 and flips bits 1–31. Negating a multiplier barely changes bias (F12), so with folding on, each multiplier is shown in whichever form has bit 31 = 0. Without it, one family shows up as two mirror-image patterns.

Read with care

These rows come from local searches, so they are not a random sample. Many good rows descend from the same few parents. A bit that all the top rows share may be inherited rather than important. The random-high-halves controls (F16) are the cleanest test, and you can isolate them with "Highlight".
